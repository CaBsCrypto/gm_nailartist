# GM NailArtist

Página web oficial de GM NailArtist, un estudio de belleza integral, nail art y cursos de uñas ubicado en Santiago, Chile.

## Características

- Catálogo de servicios actualizado (Manicure, Pedicure, Colorimetría, etc.).
- Formulario de reservas integrado directamente con WhatsApp.
- Soporte para atención presencial (Sede Ñuñoa) y A Domicilio.
- Construido con Next.js, React y Tailwind CSS.

## Comandos Útiles

- `npm run dev`: Inicia el servidor de desarrollo local.
- `npm run build`: Compila la aplicación para producción.
- `npm start`: Inicia el servidor de producción.
- `npx vercel --prod`: Despliega la aplicación directamente en Vercel.
